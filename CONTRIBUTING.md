# Contributing to Roam

Thank you for your interest in contributing to Roam!

As this is currently a personal project, please adhere to the following simple rules:

1. Create a branch for your feature or bug fix.
2. Ensure `dotnet build` passes and tests run successfully.
3. Keep PRs small and focused on a single issue.
4. Adhere to the C# coding standards (Clean Architecture).

Happy coding!
